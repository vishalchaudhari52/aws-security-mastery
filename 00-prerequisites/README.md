00 - Prerequisites

Welcome to the prerequisites section of AWS Security Mastery.

Before learning AWS Cloud Security, it is important to understand the fundamentals of cloud computing, networking, Linux, command-line tools, and Git.

📚 Learning Topics
Cloud Computing Fundamentals
Networking Fundamentals
Linux Basics
Git and GitHub Basics
JSON Fundamentals
AWS CLI Installation and Setup
Basic Python Programming
🎯 Learning Objectives

By completing this section, you should be able to:

Understand basic cloud computing concepts.
Understand IP addresses, ports, DNS, TCP and UDP.
Navigate Linux systems using terminal commands.
Understand Git and GitHub workflows.
Read and understand JSON documents.
Install and configure AWS CLI.
Understand basic Python syntax.
🧪 Practical Exercises
Practice Linux commands.
Create your first GitHub repository.
Practice Git commits and pushes.
Install AWS CLI.
Configure AWS CLI using secure authentication.
✅ Completion Criteria

Complete all prerequisite topics before moving to AWS Security Fundamentals.
