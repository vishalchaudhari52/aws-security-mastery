
# Amazon GuardDuty – Threat Detection

## 1. What is Amazon GuardDuty?

Amazon GuardDuty is an AWS threat detection service that continuously monitors your AWS environment to identify malicious activities, suspicious behavior, and potential security threats.

It helps protect your AWS accounts, workloads, and data by analyzing relevant security events and activity.

## 2. What is Threat Detection?

Threat detection is an organization's ability to monitor activities and events within its environment to identify suspicious behavior and potential security incidents.

It helps security teams detect unusual activities that may indicate a security breach or compromise.

### Example of Threat Detection

Consider the following scenario:

- You have a production server running in the US AWS Region.
- Normally, the server communicates with systems and services from expected geographical locations.
- Suddenly, after a month, the production server starts communicating with an unexpected IP address associated with North Korea.

This unusual communication could indicate suspicious activity or a potential security compromise.

This is a threat detection scenario. The security team should investigate the communication to understand:

- Why is the server communicating with an unexpected destination?
- Is the communication legitimate or malicious?
- Has the server been compromised?
- Is any sensitive data being transferred?

### Important Security Observation

Once a server is compromised, attackers may use it for malicious activities.

For example:

- Cryptocurrency mining (Bitcoin mining).
- Command-and-Control (C2) communication.
- Unauthorized access to other systems.
- Data exfiltration.
- Launching attacks against other servers.

These activities can generate unusual network traffic and should be investigated.

## 3. Important Requirement for Threat Detection

**Appropriate logging and event monitoring are essential for effective threat detection.**

Security teams need sufficient logs and event data to identify, investigate, and analyze suspicious activities.

Important sources of security data include:

- AWS CloudTrail logs – API activity and account actions.
- VPC Flow Logs – Network traffic information.
- DNS logs – DNS queries and communication patterns.
- Amazon S3 data events – S3 object-level activities.
- Operating system logs – System authentication and activity records.

Without appropriate logging and monitoring, identifying and investigating security incidents becomes difficult.

## 4. What is Amazon GuardDuty?

Amazon GuardDuty is a managed threat detection service that continuously monitors AWS environments for malicious activity and unauthorized behavior.

It helps protect:

- AWS accounts.
- EC2 instances and workloads.
- Amazon S3 data.
- Container workloads.
- Other supported AWS resources.

GuardDuty analyzes data sources such as AWS CloudTrail management events, VPC Flow Logs, and DNS logs to identify potential security threats.

It generates security findings when suspicious or malicious activity is detected.

## 5. Key Takeaways

- **Threat Detection:** Identifying suspicious activities and potential security incidents.
- **Amazon GuardDuty:** AWS managed threat detection service.
- **Logging and Monitoring:** Essential requirements for effective threat detection.
- **Security Findings:** Alerts generated by GuardDuty when potential threats are identified.
- **Incident Response:** The process of investigating and handling detected security incidents.
