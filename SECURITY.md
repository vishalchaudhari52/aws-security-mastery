🔐 Security Policy
About This Repository

AWS Security Mastery is an educational repository focused on AWS Cloud Security, defensive security practices, hands-on labs, and DevSecOps.

Supported Scope

Security-related concerns involving:

Documentation accuracy
Insecure example configurations
Exposed credentials accidentally committed
Vulnerable infrastructure examples
Insecure automation workflows
Responsible Security Practices

All practical exercises must be conducted in:

AWS accounts owned by the learner.
Authorized training environments.
Approved sandbox environments.

Unauthorized testing against third-party infrastructure is not permitted.

Credential Protection

Never commit:

AWS Access Keys
AWS Secret Keys
Passwords
API Tokens
Private Keys
Sensitive Configuration Files

Use secure credential management and temporary credentials whenever possible.

Reporting Security Issues

Please do not publish sensitive credentials or exploitable details in public issues.

For sensitive reports, contact the repository maintainer through the private contact method listed in the GitHub profile.

Security Best Practices
Enable MFA.
Follow least privilege.
Monitor AWS activity.
Review IAM permissions.
Use encryption.
Configure billing alerts.
Clean up lab resources.

Security First. Learn Responsibly.
